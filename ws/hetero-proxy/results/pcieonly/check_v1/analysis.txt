Anchor: per-GPU simultaneous host send + receive 5.95-7.3 GB/s (I2 v2) / 5.87-6.46 (Phase 0): shm_intra 7.4-7.6 is +2-29%,
at the upper edge (ring SHM moves each direction through host memory at once). Not audited.
Caveat: the nvlink small-size numbers (1 MiB AR 0.264 ms) are far above known NVSwitch latency; this script measures with a
barrier before each call and eager launches, so only the 16-128 MiB rows are used. Use nccl-tests for small sizes.
Meaning: with three NCCL variables the same 8x A100 becomes a "PCIe without P2P" machine for NCCL traffic (~7.5 GB/s busbw,
like going through host memory on a PCIe-only box). Paths that use peer pointers directly (Flux, NVSHMEM, PyTorch
SymmetricMemory / async TP, vLLM custom all-reduce) cannot be redirected and need P2P (inference; FlashOverlap 2504.19519 states
Flux requires P2P access).
